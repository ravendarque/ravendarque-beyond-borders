# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in this project, please report it privately rather than opening a public issue:

- Use [GitHub's private vulnerability reporting](https://github.com/ravendarque/ravendarque-beyond-borders/security/advisories/new) for this repository, or
- Email the maintainer at the address listed on the [GitHub profile](https://github.com/ravendarque).

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any relevant logs, screenshots, or proof-of-concept code

## Response

This is a small, actively maintained side project. There's no formal SLA, but reports are read promptly and fixes for confirmed issues are prioritized over other work. You'll get an acknowledgement and, where possible, credit in the eventual fix.

## Scope

This covers the application code, build/deploy pipeline, and GitHub Actions workflows in this repository. Third-party dependencies should be reported upstream, though flagging them here (e.g. via Dependabot alerts) is also fine.
